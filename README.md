## Getting Started

To get a local copy up and running follow these simple example steps.

### Prerequisites
* nodejs 12.x
* npm - to install packages locally

### Setup
* git clone https://github.com/AxelSoler/portfolio2.git

### Install
* cd portfolio
* npm install

### Lint code
* npx eslint .
* npx stylelint "**/*.{css,scss}"
